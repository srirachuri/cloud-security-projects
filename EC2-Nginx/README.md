# Secure EC2 Server Setup with Nginx

## Project Overview
This project demonstrates setting up and securing an AWS EC2 Ubuntu server.
The goal is to practice real-world cloud security tasks such as secure access,
log monitoring, permission handling, and service management.

## What I Did
- Connected to an AWS EC2 instance using SSH key authentication
- Verified successful login using authentication logs
- Checked system logs using journalctl
- Created and secured application directories using proper permissions
- Installed and managed the Nginx web server
- Verified running services using systemctl
- Safely stopped the EC2 instance after completion

## Tools & Technologies
- AWS EC2
- Ubuntu Linux
- SSH
- Nginx
- systemctl
- journalctl

## Security Focus
- Used key-based SSH authentication
- Reviewed authentication and system logs
- Avoided insecure permissions
- Ensured services are properly running and enabled

## Outcome
Successfully set up and validated a secure EC2 server with Nginx running.
This project reflects real-world cloud security and Linux administration tasks.
